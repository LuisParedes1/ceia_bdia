# Trabajo Práctico Integrador: Bases de Datos para Inteligencia Artificial

**Diseño de una capa de datos para recomendaciones personalizadas**
Tienda online de cosmética y perfumería


## Consigna - Sistema de recomendación para comercio electrónico

Una tienda digital desea mejorar la experiencia de compra de sus clientes mediante recomendaciones
personalizadas. La plataforma registra productos, categorías, compras, búsquedas, productos visitados,
reseñas y distintas interacciones de los usuarios con el catálogo.

Se desea diseñar una solución de datos que permita organizar la información del comercio, registrar el
comportamiento de los usuarios y generar recomendaciones basadas en historial de compras,
navegación, preferencias o similitud entre productos.

El sistema deberá contemplar que existen distintos tipos de usuarios: clientes que compran,
administradores que gestionan el catálogo, operadores que actualizan precios o stock y analistas que
consultan indicadores comerciales.

Algunos datos posibles: usuarios, productos, categorías, compras, búsquedas, eventos de navegación,
reseñas, recomendaciones, carritos, historial de interacciones, precios, stock y promociones.
