# Github page para Bases de Datos para Inteligencia Artificial

Esta es mi pagina personal para los apuntes tomados durante la cursada de Bases de Datos para Inteligencia Artificial.

La pagina fue generada usando Claude. Para mantenerlo lo mas simple posible es solo una página estática desarrollada en HTML sin dependencias ni build

Pasos para desplegar

index.html en la raíz del repositorio.
Settings → Pages → Source: Deploy from a branch → pages / root.
Queda disponible en https://TU-USUARIO.github.io/ceia_prob_estadistica/.


# Ejecutar localmente

Abrí index.html en el navegador, o levantá un servidor local:

```
python3 -m http.server
```
